# Sources for diataxis

Checked on their pages on 2026-11-11. Diátaxis is copyright Daniele
Procida and states no open licence, so it is paraphrased here, never
quoted.

- [Diátaxis](https://diataxis.fr/) names four needs a reader brings to
  documentation and one form of document for each: tutorials, how-to
  guides, reference and explanation.
- [The compass](https://diataxis.fr/compass/) decides the form with two
  questions: does the content guide action or inform understanding,
  and does it serve learning or working?
- [How to use Diátaxis](https://diataxis.fr/how-to-use-diataxis/): its
  author describes it as a guide for checking each page, not a plan of
  documents that must all be written.
- The other side: Tom Johnson, [I'd Rather Be
  Writing](https://idratherbewriting.com/blog/what-is-diataxis-documentation-framework),
  on first meeting it: splitting docs this way "seemed overly
  opinionated and arbitrary".
- Which style each kind uses, and where each kind lives, are daemorgue's
  own choices (decision-15 and decision-16 on its board). Explanation
  uses the user-documentation style because Diátaxis's explanation
  admits opinion and analogy, which the technical-writing style
  forbids.
